# Publicación HTTPS

Publicado en GitHub Pages:

https://tooncharly.github.io/ruta-viva-pwa/

Repositorio:

https://github.com/ToonCharly/ruta-viva-pwa

El proyecto puede desplegarse en Netlify:

1. Cree una cuenta en Netlify.
2. Arrastre la carpeta del proyecto al panel de Netlify Drop.
3. Conserve el archivo `netlify.toml`.
4. Netlify asignará automáticamente HTTPS.

También puede utilizar GitHub Pages desde Settings > Pages. GitHub Pages proporciona HTTPS cuando está disponible.

Para la publicación, todos los recursos deben conservar rutas relativas.
